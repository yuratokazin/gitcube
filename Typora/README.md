Я перенес картинки документа и сам документ который делал в Typora на Рабочий стол что бы подготовить его для копирования на гитхаб.

## Пример промта для ИИ

```
как изменить абсолютный путь к файлу (/home/oem/.config/Typora/typora-user-images/image-20250817212750610.png) на этот /home/oem/Рабочий стол/typora-user-images/image-20250807141306097.png но только на относительный путь
```

Чтобы изменить путь на относительный, нужно определить, где находится ваш **Markdown-файл** (.md) относительно папки с изображениями.

#### 1. Если файл лежит на «Рабочем столе»

По умолчанию `.md` файл находится в папке  (/home/oem/.config/Typora/typora-user-images/image-20250817212750610.png), я же перенес всю папку typora-user-images на`/home/oem/Рабочий стол/`,  то путь сокращается до:

```
./typora-user-images/image-`20250807141306097.png
```

#### 2. Универсальный синтаксис

В Markdown это будет выглядеть как выше или так:
`![Название](typora-user-images/image-20250807141306097.png)`

Как настроить это в Typora (автоматически):

Чтобы не менять пути вручную, в Typora есть удобная настройка:

1. Зайдите в **Файл** -> **Настройки** (Preferences).
2. Выберите вкладку **Изображения** (Image).
3. В выпадающем списке выберите «Копировать изображение в папку...» (Copy image to custom folder).
4. Укажите имя папки (например, `assets` или `typora-user-images`).
5. **Важно:** Поставьте галочку **«Использовать относительный путь по возможности»** (Use relative path if possible).

---

##### Подсказать, как массово заменить пути во всем документе через «Поиск и замену»?

Да

Для массовой замены в Typora (или любом текстовом редакторе) используйте сочетание клавиш 

**Ctrl + H**.

В появившемся окне введите следующие данные:

1. **Найти (Find):** `/home/oem/.config/Typora/`
2. **Заменить на (Replace with):** Оставьте это поле **пустым** (если файл лежит прямо на Рабочем столе) или введите `./` (точка и слэш).
3. Нажмите кнопку **«Заменить все» (Replace All)**.

Важные нюансы:

- **Проверьте кодировку:** Если путь содержит кириллицу («Рабочий стол»), убедитесь, что редактор корректно её распознаёт.
- **Относительность:** Если ваш `.md` файл лежит в подпапке, а картинки на уровень выше, то вместо пустого поля нужно использовать `../`.
- **Режим исходного кода:** В Typora лучше делать это в режиме «Исходного кода» (**Ctrl + /**), чтобы видеть прямые ссылки без визуального оформления.

## Как добавить картинку

Как проверить моментально:

1. В Typora нажмите **Ctrl + /** (режим исходного кода).
2. Удалите строку с картинкой.
3. Просто **перетащите** файл `image-20250817212750610.png` из папки прямо в текст Typora.
4. Посмотрите, какой путь она пропишет сама.

**Если перетаскивание снова создает длинный путь `/home/oem/...`, значит, в настройках Typora не включена опция «Use relative path». Включи её.**
