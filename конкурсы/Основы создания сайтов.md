# Основы создания сайтов

**1. Что такое хостинг?**

- А) Программа для создания дизайна сайта
- Б) Место на сервере, где хранятся файлы сайта
- В) Адрес сайта в интернете
- Г) Язык программирования 

**2. Какой вид хостинга лучше всего подходит для небольшого, только что созданного сайта-визитки?**

- А) Выделенный сервер
- Б) Облачный сервер (Cloud)
- В) Виртуальный (Shared) хостинг
- Г) Колокейшн (Colocation) 

**3. Какой HTML-тег используется для создания главной заголовка страницы (самого важного)?**

- А) `<h6>`
- Б) `<header>`
- В) `<h1>`
- Г) `<title>` 

**4. Что из перечисленного является CMS (системой управления контентом)?**

- А) HTML
- Б) WordPress
- В) Adobe Photoshop
- Г) Google Chrome 

**5. Для чего используется CSS в создании сайтов?**

- А) Для создания структуры страницы
- Б) Для оформления внешнего вида (дизайна) элементов
- В) Для написания функционала сайта
- Г) Для хранения данных пользователей 

**6. Что такое доменное имя?**

- А) Папка, где лежит сайт
- Б) Адрес сайта в интернете (например, google.com)
- В) Логин администратора
- Г) Имя разработчика сайта 

**7. Какой тег HTML используется для создания ссылки?**

- А) `<img>`
- Б) `<link>`
- В) `<a>`
- Г) `<href>` 

**8. Что такое адаптивный дизайн?**

- А) Дизайн, который меняет цвета
- Б) Дизайн, который красиво отображается на экранах разного размера (телефоны, ПК)
- В) Дизайн, созданный в конструкторе
- Г) Дизайн, который быстро загружается 

**9. Что обычно находится внутри тега `<head>` в HTML-документе?**

- А) Основной текст сайта
- Б) Техническая информация, CSS, заголовок вкладки
- В) Изображения сайта
- Г) Подвал сайта (footer) 

**10. Для чего нужен FTP?**

- А) Для написания HTML-кода
- Б) Для загрузки файлов сайта на хостинг
- В) Для создания базы данных
- Г) Для редактирования изображений
