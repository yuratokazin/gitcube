Этот тест поможет проверить базовые знания о создании простых сайтов: выбор хостинга, HTML-структуру, работу с CMS и дизайн.

Тест: Основы создания сайта (10 вопросов)

**1. Что такое доменное имя сайта?**

- А) Адрес сервера, где хранятся файлы
- Б) Уникальный адрес сайта в сети (например, site.ru)
- В) Программа для написания кода
- Г) Язык разметки страниц 

**2. Где физически хранятся файлы сайта, чтобы он был доступен 24/7?**

- А) На домашнем компьютере
- Б) На флешке
- В) На хостинге (сервере)
- Г) В браузере 

**3. Какой язык используется для создания структуры веб-страницы?**

- А) PHP
- Б) CSS
- В) HTML
- Г) SQL 

**4. За что отвечает CSS в создании сайта?**

- А) За функционал (формы обратной связи)
- Б) За дизайн и внешнее оформление
- В) За наполнение контентом
- Г) За название домена 

**5. Что такое CMS (например, WordPress)?**

- А) Язык программирования
- Б) Система управления контентом сайта
- В) Программа для дизайна
- Г) Название хостинга 

**6. Какой тег в HTML используется для создания гиперссылки?**

- А) `<link>`
- Б) `<a>`
- В) `<p>`
- Г) `<url>` 

**7. Какое разрешение файла используется для главной страницы сайта?**

- А) `index.html`
- Б) `main.css`
- В) `home.php`
- Г) `index.txt` 

**8. Что такое «адаптивная верстка»?**

- А) Сайт, который долго грузится
- Б) Сайт, корректно отображающийся на разных устройствах
- В) Сайт с ярким дизайном
- Г) Сайт, созданный только для ПК 

**9. Что такое «favicon»?**

- А) Значок сайта во вкладке браузера
- Б) Заголовок статьи
- В) Кнопка «Купить»
- Г) Фоновая картинка 

**10. Для чего нужен «конструктор сайтов» (Tilda, Wix)?**

- А) Для написания кода вручную
- Б) Для создания сайтов без программирования
- В) Для покупки доменов
- Г) Для взлома сайтов 

------

Ответы

1. **Б** (Уникальный адрес сайта)
2. **В** (На хостинге)
3. **В** (HTML)
4. **Б** (Дизайн и оформление)
5. **Б** (Система управления контентом)
6. **Б** (`<a>`)
7. **А** (`index.html`)
8. **Б** (Корректное отображение на разных устройствах)
9. **А** (Значок сайта)
10. **Б** (Создание сайтов без программирования)
