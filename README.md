Примеры готовых шаблонов для сайта визитки, блога и т.д. https://nethouse.ru/design

Для регистрации на [GitHub](https://github.com/), зайдите на сайт, нажмите «Sign up», введите свой email, создайте пароль и уникальный логин. Подтвердите электронную почту с помощью кода из письма, решите капчу (головоломку) и нажмите «Create account». Выберите бесплатный тариф, пропустив персонализацию, чтобы сразу начать работу. 

**Пошаговая инструкция:**

1. **Начало:** Перейдите на github.com и нажмите кнопку «Sign up» в правом верхнем углу.
2. **Ввод данных:** Введите действующий адрес электронной почты.
3. **Пароль и логин:** Создайте надежный пароль (минимум 8 символов, включая цифры и строчные буквы) и уникальное имя пользователя (username).
4. **Подтверждение:** Получите 8-значный код на почту и введите его в поле проверки.
5. **Верификация:** Решите простую головоломку (капчу), чтобы доказать, что вы не робот.
6. **Завершение:** Нажмите «Create account». Пропустите дополнительные настройки (Skip personalization), чтобы попасть в личный кабинет. 

После этого можно создавать репозитории, выбрав бесплатный тариф (Free), который подходит для большинства пользователей.

Теперь всё понятно. **"Pending Invite"** в разделе **Collaborators** на GitHub означает, что вас пригласили в качестве collaborator'a (соавтора) в чей-то репозиторий.

Чтобы принять это приглашение, у вас есть **три основных способа**.

### Способ 1: Через Email (Самый простой)

1.  Проверьте почту, которую вы привязали к аккаунту на GitHub.
2.  Найдите письмо от **GitHub** с темой похожей на `[user] invited you to collaborate on the [repository] repository`.
3.  Внутри письма будет большая зеленая кнопка **View invitation**.
4.  Нажмите на нее, и вас перебросит на GitHub на страницу принятия приглашения. Там нужно нажать еще одну кнопку **Accept invitation**.

### Способ 2: Прямая ссылка на приглашение

Просто перейдите по этой прямой ссылке, будучи авторизованным в своём аккаунте GitHub:
**https://github.com/notifications** или конкретно **https://github.com/user/repo/invitations**

GitHub автоматически перенаправит вас на нужное pending-приглашение.

### Способ 3: Через интерфейс GitHub (вручную)

1.  **Зайдите на GitHub.com** и убедитесь, что вы вошли в аккаунт **@Davydov-Kirill**.
2.  В правом верхнем углу главной страницы найдите иконку **колокольчика (Notifications)** 🔔.
    

3.  Нажмите на нее. В выпадающем списке уведомлений найдите приглашение в репозиторий. Оно будет помечено как **"Invitation"**. Рядом будет кнопка **Accept**.
    *(Если в выпадающем списке его нет, нажмите "See all", чтобы перейти на полную страницу уведомлений).*
4.  Нажмите **Accept**.

---

**Что произойдет после этого?**

*   Репозиторий, в который вас пригласили, появится в списке ваших репозиториев на главной странице.
*   Вы получите доступ на запись (write access) к этому репозиторию (если владелец не указал другие права) и сможете делать push, создавать ветки, issues и пул-реквесты.

Если ни один из способов не сработал, возможно, приглашение устарело или было отозвано. В таком случае попросите владельца репозитория отправить приглашение заново.

Чтобы создать дополнительные репозитории в вашем GitHub аккаунте, следуйте этим шагам:

## Создание нового репозитория

1. **Войдите в GitHub** и перейдите на главную страницу
2. **Нажмите кнопку "+"** в правом верхнем углу
3. **Выберите "New repository"**

## Заполнение информации о репозитории

- **Repository name**: Укажите название репозитория
- **Description**: Добавьте описание (опционально)
- **Visibility**: Выберите:
  - **Public** - виден всем
  - **Private** - только вам и выбранным пользователям

## Дополнительные настройки

- **Initialize with a README** - создаст README файл
- **Add .gitignore** - выберите шаблон для игнорирования файлов
- **Choose a license** - выберите лицензию для проекта

## После создания

После нажатия "Create repository" вы сможете:
- Клонировать репозиторий на локальную машину
- Добавлять файлы и код
- Делать коммиты и пушить изменения

## Альтернативные способы

### Через командную строку
```bash
# Создать новую папку и инициализировать git
mkdir new-repo
cd new-repo
git init

# Добавить файлы
echo "# Новый проект" > README.md
git add .
git commit -m "Initial commit"

# Добавить удаленный репозиторий
git remote add origin https://github.com/yuratokazin/new-repo.git
git push -u origin main
```

### Через GitHub CLI
```bash
gh repo create new-repo --public --description "Описание репозитория"
```

Вы можете создавать неограниченное количество публичных репозиториев в своем аккаунте!

Отлично! Вы склонировали репозиторий и добавили в него файлы. Теперь нужно выполнить несколько шагов, чтобы добавить эти изменения в ваш репозиторий на GitHub.

Вот пошаговая инструкция:

## 1. Перейдите в папку репозитория
```bash
cd ~/Lesson001-
```

## 2. Проверьте статус репозитория
```bash
git status
```
Вы должны увидеть, что файлы `index.html`, `jscript.js` и `style.css` отображаются как "неотслеживаемые" (untracked) красным цветом.

## 3. Добавьте файлы в отслеживание
```bash
# Добавить все файлы в текущей директории
git add .

# ИЛИ можно добавить файлы по отдельности
git add index.html jscript.js style.css
```

## 4. Проверьте статус снова
```bash
git status
```
Теперь файлы должны отображаться зеленым цветом как готовые к коммиту.

## 5. Создайте коммит
```bash
git commit -m "Добавлены файлы HTML, CSS и JavaScript"
```

## 6. Отправьте изменения на GitHub
```bash
git push origin main
```
Если ветка называется `master` вместо `main`:
```bash
git push origin master
```

## Проверка имени ветки
Если вы не уверены, какая у вас ветка:
```bash
git branch
```

## Полная последовательность команд:
```bash
cd ~/Lesson001-
git status
git add .
git status
git commit -m "Добавлены файлы HTML, CSS и JavaScript"
git push origin main
```

После выполнения этих шагов ваши файлы будут загружены в ваш репозиторий на GitHub. Вы можете проверить это, зайдя на страницу вашего репозитория в браузере.
