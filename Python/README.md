## Как правильно работать в Thonny

### Вариант 1. Интерактивный режим (оболочка Python)

1. Откройте Thonny. Внизу по умолчанию активна оболочка (с приглашением `>>>`).
2. Вводите команды:

```python
>>> 2 + 3
5
>>> print("Привет, мир!")
Привет, мир!
>>> name = "Анна"
>>> age = 35
>>> print(name, age)
Анна 35
```

Нажимайте `Enter` после каждой строки — результат отобразится сразу.

### Вариант 2. Редактор кода (скрипт)

1. Создайте новый файл: `Файл → Новый` или `Ctrl+N`.

2. Напишите код в редакторе:

   python

1. ```python
   # Программа: Приветствие пользователя
   name = input("Как вас зовут? ")
   print("Рад познакомиться,", name + "!")
   ```

2. Сохраните файл: `Файл → Сохранить` или `Ctrl+S`, назовите, например, `greeting.py`.

3. Запустите программу: `Запуск → Запустить текущий скрипт` или `F5`.

4. Введите имя в появившемся окне — программа выведет результат.

## Пошаговое решение вашей задачи

**Цель:** выполнить арифметические операции и вывести текст в Thonny.

**Шаг 1. В интерактивном режиме (оболочка)**

В окне с `>>>` введите:

```python
>>> 2 + 3
5
>>> 10 / 2
5.0
>>> 5 ** 2
25
>>> print("Привет, мир!")
Привет, мир!
>>> name = "Анна"
>>> age = 35
>>> print(name, age)
Анна 35
```

**Шаг 2. В редакторе кода (скрипт)**

Создайте новый файл (`Ctrl+N`).

Введите код:

```python
# Калькулятор сложения
num1 = int(input("Введите первое число: "))
num2 = int(input("Введите второе число: "))
result = num1 + num2
print("Сумма:", result)
```

Сохраните как `calculator.py` (`Ctrl+S`).

Запустите (`F5`).

Введите два числа по запросу — программа покажет сумму.

## Ключевые правила для Thonny

- В оболочке (`>>>`) команды выполняются сразу после `Enter`.
- В редакторе код сохраняется в файл и запускается целиком (`F5`).
- Следите за кавычками и скобками: `print("Текст")` — правильно, `print(Текст)` — ошибка.
- Для ввода данных используйте `input()`, для вывода — `print()`.
- Преобразуйте ввод в число через `int(input())`, если нужны арифметические операции.

## Проверка и отладка

Если появляется ошибка:

1. Посмотрите на строку, указанную в `Traceback`.
2. Проверьте синтаксис: кавычки, скобки, отсутствие `$`.
3. Используйте **ассистент Thonny** — он подсвечивает проблемные места и даёт подсказки.

Пример ошибки и исправления:

**Неправильно:**

```python
$ print(Привет, мир!)
```

**Правильно:**

python

```python
print("Привет, мир!")
```

- В оболочке пишите код после `>>>`.
- В редакторе сохраняйте файл и запускайте через `F5`.
