## Как запустить интерактивную оболочку Python в Geany

Установка Geany

```
sudo apt install geany
```

**Способ 1. Через встроенный терминал**

1. Откройте Geany.
2. Внизу окна найдите панель **«Терминал»** (если её нет, включите через **«Вид» → «Терминал»**).
3. В терминале введите команду:
   - `python` (для Windows);
   - `python3` (для Linux/macOS).
4. Нажмите **Enter** — откроется интерактивная оболочка Python с приглашением `>>>`.
5. Теперь можно вводить команды напрямую:

```
>>> 2 + 3
5
>>> print("Привет, мир!")
Привет, мир!
```

**Способ 2. Через командную строку/терминал вне Geany**

1. Закройте Geany (необязательно, но так будет чище).
2. Откройте системный терминал:
   - в Windows — **cmd** или **PowerShell**;
   - в Linux — **Ctrl+Alt+T**;
   - в macOS — **Terminal**.
3. Введите `python` или `python3`, нажмите **Enter**.
4. Работайте в интерактивной оболочке как обычно.

## Как создать и запустить скрипт в Geany

**Шаг 1. Создайте новый файл**

- **«Файл» → «Новый»** или **Ctrl+N**.

**Шаг 2. Напишите код**

Пример программы приветствия:

python

```python
# Программа: Приветствие пользователя
name = input("Как вас зовут? ")
print("Рад познакомиться,", name + "!")
```

**Шаг 3. Сохраните файл**

- **«Файл» → «Сохранить»** или **Ctrl+S**.
- Назовите файл с расширением `.py`, например, `greeting.py`.

**Шаг 4. Настройте сборку (один раз)**

1. Перейдите в **«Сборка» → «Установить команды сборки»**.
2. В разделе **«Выполнить»** укажите команду:
   - для Windows: `python "%f"`;
   - для Linux/macOS: `python3 "%f"`.
3. Нажмите **«Закрыть»**.

**Шаг 5. Запустите скрипт**

- **«Сборка» → «Выполнить»** или **F5**.
- Введите имя в появившемся окне терминала.
- Программа выведет результат.

## Пошаговое решение задачи в Geany

**Цель:** выполнить арифметические операции и вывести текст.

**Вариант 1. В интерактивной оболочке**

1. Откройте терминал в Geany (**Вид» → «Терминал»**, если скрыт).
2. Введите `python3` и нажмите **Enter**.
3. Выполните команды:

```
>>> 2 + 3
5
>>> 10 / 2
5.0
>>> 5 ** 2
25
>>> name = "Анна"
>>> age = 35
>>> print(name, age)
Анна 35
```

**Вариант 2. В редакторе кода**

1. Создайте новый файл (**Ctrl+N**).
2. Введите код калькулятора:

python

```python
# Калькулятор сложения
num1 = int(input("Введите первое число: "))
num2 = int(input("Введите второе число: "))
result = num1 + num2
print("Сумма:", result)
```

1. Сохраните как `calculator.py` (**Ctrl+S**).
2. Запустите (**F5** или **«Сборка» → «Выполнить»**).
3. Введите два числа — программа покажет сумму.

## Ключевые правила для Geany

- **Интерактивный режим:** используйте встроенный терминал Geany или внешний терминал.
- **Редактор кода:**
  - сохраняйте файлы с расширением `.py`;
  - перед первым запуском настройте команды сборки;
  - запускайте скрипты через **F5** или **«Сборка» → «Выполнить»**.
- **Синтаксис:**
  - строки заключайте в кавычки: `print("Текст")`;
  - преобразуйте ввод в число: `int(input())` для арифметики.
- **Расширение файла:** всегда `.py` — иначе Geany не распознает Python‑код.
- **Подсветка синтаксиса:** Geany автоматически подсвечивает ошибки — используйте это для отладки.

------

## Проверка и отладка

Если появляется ошибка:

1. Посмотрите на сообщение **Traceback** — оно указывает строку и тип ошибки.
2. Проверьте:
   - закрыты ли все кавычки и скобки;
   - нет ли случайных символов (например, `$`);
   - правильный ли тип данных (строка vs число).
3. Убедитесь, что файл сохранён с расширением `.py`.
4. Перепроверьте настройки сборки (**Сборка» → «Установить команды сборки»**).

**Пример ошибки и исправления**

Неправильно:

```
print(Привет, мир!)
```

Правильно:

python

```python
print("Привет, мир!")
```

## Краткий итог

Чтобы избежать `SyntaxError` и других проблем:

- Для интерактивного режима используйте терминал Geany (`python3`) или внешний терминал.
- Для скриптов:
  - создавайте файл в Geany;
  - сохраняйте с расширением `.py`;
  - настраивайте сборку один раз;
  - запускайте через **F5**.
