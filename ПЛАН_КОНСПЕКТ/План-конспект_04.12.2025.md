- 3 балла — базовые стили для всех секций

- 2 балла — чистота и читаемость HTML
- 2 балла — чистота и читаемость CSS

- 2 балла — корректное отображение в браузере

### 3. Шаблон структуры файлов и кода

**Структура проекта:**

```
portfolio/
├── index.html
├── style.css
├── images/
│   └── [изображения]
└── fonts/
    └── [шрифты]
```

**index.html**

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Семантический макет</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header class="header">
        <!-- Контент шапки -->
    </header>

    <main class="main">
        <!-- Основной контент -->
    </main>

    <footer class="footer">
        <!-- Подвал сайта -->
    </footer>
</body>
</html>
```

**style.css**

```css
/* Базовые стили */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    font-family: Arial, sans-serif;
    line-height: 1.6;
    color: #333;
}

/* Стили для header */
.header {
    /* Ваши стили */
}

/* Стили для main */
.main {
    /* Ваши стили */
}

/* Стили для footer */
.footer {
    /* Ваши стили */
}

/* Адаптивные стили */
@media (max-width: 768px) {
    /* Мобильные стили */
}
```
