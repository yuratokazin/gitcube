### Цель занятия

Сформировать у обучающихся практические навыки создания семантически корректной  HTML‑структуры и базового оформления CSS на примере макета  сайта‑портфолио.

------

### Задачи

1. **Образовательная:**
   - закрепить знания о семантических тегах HTML (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`);
   - отработать навыки написания валидного HTML и CSS;
   - научиться структурировать макет по секциям согласно ТЗ.
2. **Развивающая:**
   - развивать логическое мышление при разбиении макета на блоки;
   - формировать навык самопроверки по чек‑листу;
   - тренировать умение работать в паре (взаимопроверка, обсуждение решений).
3. **Воспитательная:**
   - воспитывать аккуратность в коде и внимание к деталям;
   - способствовать формированию культуры обратной связи в команде.

------

### Форма занятия

- Фронтальная (объяснение, демонстрация);
- Групповая (работа в парах над макетом);
- Индивидуальная (самостоятельная вёрстка, самопроверка).

------

### Оборудование и МТБ

- Компьютеры с доступом в интернет;
- Редактор кода (VS Code, Sublime Text или аналогичный);
- Браузер (Chrome/Firefox);
- Проектор и экран для демонстрации;
- Раздаточные материалы:
  - карточка с критериями оценки;
  - чек‑лист для самопроверки;
  - шаблон структуры файлов и кода (раздаётся в начале практики).

### План занятия (90 мин)

1. **Организационная часть** (5 мин)
   - приветствие, проверка присутствия;

2. **Актуализация опорных знаний** (10 мин)

   - разбор типичных ошибок в структуре макета (на примерах).
3. **Освоение нового материала** (15 мин)
   - демонстрация эталонного макета (вариант А — сайт‑портфолио);
   - пояснение структуры файлов проекта (`index.html`, `css/style.css`, папки `images/`, `js/`);
   - обзор ключевых CSS‑свойств для сетки, отступов, типографики;

4. **Закрепление новой темы** (40 мин)

     - учащиеся выбирают вариант макета (А/Б/В) или работают в парах;

   - краткие отзывы учащихся о паре (что было полезно в совместной работе).
6. **Подведение итогов** (10 мин)
   - анализ выполненных работ (2–3 примера на проекторе);
   - комментарии по критериям оценки;
   - объявление домашних заданий;
   - ответы на вопросы.

### Ход занятия

#### 1. Организационная часть (5 мин)

- Приветствие.
- Проверка явки.
- Объявление темы и цели: «Сегодня мы отработаем вёрстку семантического макета на  практике. Результат — рабочий шаблон сайта с чистой структурой и базовым дизайном».
- Краткий тайм‑план: «40 минут на практику, 10 на рефлексию и итоги».

#### 2. Теоретическая часть (25 мин суммарно: 10 + 15)

- **Актуализация (10 мин):**
  - фронтальный опрос по семантическим тегам;
  - обсуждение кейсов: «Как пользователь и поисковик “видят” несемантичный код?».
- **Объяснение нового (15 мин):**
  - показ структуры файлов;
  - разбор HTML‑разметки секции `<header>` и `<footer>`;
  - демонстрация CSS‑стилей для сетки (`grid`, `flex`);
  - пример медиа‑запроса для мобильных.

#### 3. Практическая часть (40 мин)

- Учащиеся:
  1. Создают папку проекта и файлы.
  2. Копируют шаблон HTML/CSS (разданный материал).
  3. Заполняют секции контентом (тексты, изображения).
  4. Настраивают отступы, шрифты, цвета.
  5. Проверяют адаптивность.
- Преподаватель:
  - консультирует по ходу работы;
  - обращает внимание на типичные ошибки (отсутствие `alt` у картинок, неверные отступы).

#### 4. Закрепление и рефлексия (10 мин)

- Пары обмениваются работами, заполняют чек‑лист (5 мин).
- Обсуждение в группе: «Что было сложным? Что получилось легко?» (5 мин).

#### 5. Подведение итогов (10 мин)

- Демонстрация 2–3 работ на экране (с комментариями).
- Оценка по критериям: структура, семантика, стили, адаптивность.
- Домашнее задание:
  - доработать макет (если не завершено);
  - добавить 1–2 анимационных эффекта на CSS (опционально).
- Ответы на вопросы.
- Благодарность за работу.
